## Shared Types
- `MarsFact`: `{ id: string, title: string, description: string, image_url: string, facts: string[] }`
- `SoundTrigger`: `{ id: string, url: string, event: 'hover' | 'click' | 'scroll' | 'load' }`
- API Response envelope: `{ status: 'ok' | 'error', data?: MarsFact[] | SoundTrigger[], message?: string }`
- Animation Config: `{ selector: string, type: 'rotate' | 'pulse' | 'path', duration: number, easing: string }`

## API Contract
- `GET /api/mars/data` -> Returns `MarsFact[]`
- `GET /api/mars/sounds` -> Returns `SoundTrigger[]`
- `GET /` -> Serves `index.html`
- All API routes return JSON with `Content-Type: application/json`
- Error handling returns 4xx/5xx with `{ status: 'error', message: string }`

## Naming Conventions
- Python: `snake_case` for functions/vars, `PascalCase` for classes, module names lowercase
- JS: `camelCase` for functions/vars, `PascalCase` for classes/constructors, `SCREAMING_SNAKE` for constants
- CSS: `kebab-case` for class names, BEM structure (`block__element--modifier`)
- HTML: semantic elements, `data-*` attributes for JS hooks, lowercase tags
- Assets: `kebab-case` for filenames, organized by type (`/assets/svg/`, `/assets/audio/`)

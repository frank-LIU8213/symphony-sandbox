## Shared Types

- **Board**: 2D array (8x8) where each cell is `null` (empty), `'black'`, or `'white'`.
- **Position**: `{ row: number, col: number }`
- **FlippedDiscs**: array of `Position` objects.
- **Score**: `{ black: number, white: number }`
- **Player**: `'black'` | `'white'`
- **GameResult**: `'black'` | `'white'` | `'draw'` | `null`
- DOM IDs used in HTML: `#app` (main container), `#board` (board element), `#info-panel` (score/turn/reset area).

## API Contract

### gameLogic.js

Constants:
- `BOARD_SIZE = 8`
- `BLACK = 'black'`
- `WHITE = 'white'`

Exported functions:
- `createBoard(): Board` – returns initial board with 4 centre discs (BLACK on (3,4) & (4,3), WHITE on (3,3) & (4,4)).
- `isValidMove(board: Board, row: number, col: number, player: Player): boolean`
- `getFlippedDiscs(board: Board, row: number, col: number, player: Player): Position[]` – discs that would be flipped if moved here.
- `placeDisc(board: Board, row: number, col: number, player: Player): { newBoard: Board, flippedDiscs: Position[] }` – returns updated board (shallow copy) and flipped positions.
- `getValidMoves(board: Board, player: Player): Position[]`
- `getScore(board: Board): Score`
- `isGameOver(board: Board): boolean`
- `getWinner(board: Board): Player | 'draw' | null` – returns winner or draw or null if not over.

### boardRenderer.js

Class `BoardRenderer`:
- `constructor(containerElement: HTMLElement, options?: { onCellClick?: (row: number, col: number) => void })`
  - Builds board DOM inside `containerElement`.
  - `onCellClick` called when a cell is clicked (passes row,col).
  - Board element must have id `board`.
- `render(board: Board, validMoves: Position[] = [])`
  - Updates DOM to reflect board state; adds class `.valid-move` to cells that are in validMoves.
  - Each cell must have class `.cell` and, if occupied, a child `.disc` with class `.disc--black` or `.disc--white`.
- `highlightFlipping(cells: Position[])`
  - Adds CSS class `.disc--flipping` to each disc in those cells and removes it after 300ms.
- `destroy()` – removes board DOM.

### infoPanel.js

Function `createInfoPanel(containerElement: HTMLElement)` returns an object:
- `updateScore(black: number, white: number): void` – updates score texts (elements with id `black-score`, `white-score`).
- `updateTurn(player: Player): void` – updates turn indicator (element with id `turn-indicator`).
- `showGameOver(winner: Player | 'draw', score: Score): void` – displays a modal/dialog with winner and final score; must have a close button.
- `reset(callback: () => void): void` – attaches click handler to a reset button (id `reset-btn`) that invokes callback.

### generateBackground.js

- `loadBackgroundImage(): Promise<string>` – returns a promise that resolves to a CSS `url(...)` string (or `none`) to be set as `document.body.style.backgroundImage`.

### Integration driver (main.js)

- `import { createBoard, getValidMoves, placeDisc, getScore, isGameOver, getWinner } from './gameLogic.js';`
- `import { BoardRenderer } from './boardRenderer.js';`
- `import { createInfoPanel } from './infoPanel.js';`
- `import { loadBackgroundImage } from './generateBackground.js';`

Runs on `DOMContentLoaded`, wires modules:
  1. Calls `loadBackgroundImage` and applies result.
  2. Creates `BoardRenderer` inside `#app`, passing `onCellClick` handler that executes game logic.
  3. Calls `createInfoPanel` to get info panel methods; attaches reset callback.
  4. Maintains current turn (`'black'` initially) and calls `render`/update methods after each valid move.
  5. After move, checks `isGameOver` and calls `showGameOver` if true.

## Shared Types
- `AnimationEngine`: Manages SVG particle systems and JS-driven transforms. Exports `initAnimations(root: HTMLElement): void` and `triggerAnimation(target: 'atom' | 'light-particle'): void`.
- `InteractionController`: Handles DOM events for interactive demos (mass sliders, speed toggles). Exports `initInteractions(root: HTMLElement): void`.
- `SoundManager`: Wraps Web Audio API for procedural sci-fi SFX. Exports `initSounds(): Promise<void>` and `playSound(type: 'click' | 'whoosh' | 'hum' | 'alarm'): void`.
- `App`: Bootstraps the site, initializes modules in dependency order, and manages global state. Exports `initApp(): void`.

## API Contract
- `src/main.js` is the application entry point. It imports all modules, calls `initSounds()` on first user gesture, then `initAnimations(app)`, then `initInteractions(app)`, and attaches a global `DOMContentLoaded` listener.
- `index.html` serves as the single-page shell. It contains `<main id="app">` with three semantic sections: `#hero` (SVG atom/light intro), `#mass-energy` (E=mc² simulator), `#light-speed` (velocity visualization). It loads `src/main.js` via `<script type="module">`.
- `styles.css` defines the tech-sci-fi theme, grid/flex layouts, and responsive breakpoints. It must not be modified by JS agents.
- `src/animations.js` operates exclusively on SVG elements inside `#hero` and `#light-speed`. It must not touch DOM outside these containers.
- `src/interactions.js` operates exclusively on form controls inside `#mass-energy` and `#light-speed`. It must not touch DOM outside these containers.
- `src/sounds.js` initializes `AudioContext` lazily on first user gesture. All `playSound` calls must be synchronous wrappers around queued audio nodes.

## Naming Conventions
- JavaScript: `camelCase` for functions/variables, `UPPER_SNAKE_CASE` for constants, `PascalCase` for classes. JSDoc `@typedef` used for all public interfaces.
- CSS: `kebab-case` for class names, BEM-like structure (`section__element--state`). No inline styles.
- SVG: `id` attributes must exactly match JS selector strings. Use `<g>` groups for animation targets.
- File paths: forward slashes, `src/` prefix for JS modules.

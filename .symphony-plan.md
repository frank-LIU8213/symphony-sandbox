## Shared Types

All modules operate on the following shared types, defined in JSDoc style within `types.js` (a standalone type-definition module) and accessible as global `MedRemTypes` namespace (optional but recommended). The existing modules (medications, schedule, logging) already use these shapes implicitly; new modules must remain compatible.

### Medication
```js
/**
 * @typedef {Object} Medication
 * @property {string} id - unique UUID assigned on creation
 * @property {string} name - medication name
 * @property {string} dosage - e.g. "500mg"
 * @property {Schedule} schedule
 */
```

### Schedule
```js
/**
 * @typedef {Object} Schedule
 * @property {string} type - 'daily' | 'weekly' | 'biweekly' | 'monthly' | 'custom'
 * @property {string[]} times - array of 'HH:MM'
 * @property {number[]} [days] - 0=Sun..6=Sat, used when type is 'weekly' or 'custom'
 * @property {string} [startDate] - ISO date string for recurring biweekly/monthly schedules
 * @property {number} [intervalValue] - weeks between doses for biweekly type
 * @property {number} [dayOfMonth] - day of month for monthly type
 */
```

### Dose
```js
/**
 * @typedef {Object} Dose
 * @property {string} id - unique identifier, usually `${med.id}_${time}`
 * @property {string} medicationId
 * @property {string} medicationName
 * @property {string} dosage
 * @property {Date} dueDate
 * @property {string} time - 'HH:MM'
 */
```

### HistoryEntry (used by logging module)
```js
/**
 * @typedef {Object} HistoryEntry
 * @property {string} doseId
 * @property {string} medicationName
 * @property {string} takenAt - ISO string
 */
```

## API Contract

Every new module exports its public API on a global namespace under `window.MedRem*`. The integrator (`w_integrator`) will call these in a defined order after DOMContentLoaded. Modules **must not** modify `index.html` or `main.js` directly; they inject UI elements via JavaScript if needed.

### MedRemAnimations (animations.js)
- `initAnimations(options?: {enableFadeIn?: boolean, enablePulse?: boolean})` – attach necessary listeners or observers to trigger animations on DOM changes. Returns void.
- `pulseDoseItem(element: HTMLElement)` – apply a pulsing animation to a specific dose card.
- `animateDoseTaken(element: HTMLElement, callback?: () => void)` – smooth transition (e.g., scale down + opacity) when a dose is marked taken, then invoke optional callback.
- `fadeInSection(container: HTMLElement)` – fade-in a whole section container.

### MedRemDecorations (decorations.js)
- `initDecorations(options?: {headerText?: string, particleCount?: number})` – inject a styled header, footer, and floating decorative elements (e.g., pills, leaves) into `document.body`. Returns void.

### MedRemTheming (theming.js)
- `initThemeToggle(containerId?: string)` – create a sun/moon toggle button and prepopulate theme from localStorage. If `containerId` is provided, appends the toggle inside that element; otherwise appends to `<body>`.
- `getCurrentTheme(): 'light' | 'dark'` – returns current active theme.
- `applyTheme(theme: 'light' | 'dark')` – applies the theme by toggling a class on `<html>` and persisting to localStorage. Emits a custom event `medrem-theme-changed` on `document`.

### MedRemSound (sound.js)
- `initSoundSettings(containerId?: string)` – inject a settings panel (sound picker, volume slider) into the designated container or body. Loads saved preferences from localStorage.
- `playSound(type?: string)` – plays the currently selected sound at the stored volume. If `type` is provided, plays that sound instead (e.g., 'chime', 'beep', 'melody').
- `setVolume(level: number)` – updates volume (0–1) and persists to localStorage.

All public functions must be safe to call multiple times (idempotent where reasonable).

## Naming Conventions
- Global namespace: `MedRem<ModuleName>` (e.g., `MedRemAnimations`, `MedRemDecorations`, `MedRemTheming`, `MedRemSound`).
- CSS classes: prefix `med-` followed by module and purpose, e.g., `.med-decorations-header`, `.med-theme-toggle`, `.med-sound-settings`.
- Custom events: `medrem-<event-name>`.
- DOM id attributes: `med-<module>-<element>` (e.g., `med-theme-toggle-btn`, `med-sound-panel`).
- File names: lowercase with hyphens, e.g., `animations.js`, `decorations.css`.
- Persistent storage keys: `medrem_<module>_<data>` (e.g., `medrem_theme_preference`, `medrem_sound_settings`). Do not collide with existing keys `medrem_medications` and `medrem_history`.
- JSDoc types: all parameters and return values must be annotated. Every public function must have a JSDoc comment.

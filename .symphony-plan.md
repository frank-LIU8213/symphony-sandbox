## Shared Types

- **TimerState** (object): `{ mode: 'work' | 'break', timeRemaining: number (seconds), isRunning: boolean, workDuration: number, breakDuration: number, sessionCount: number }`
- **TimerMode** (type): `'work' | 'break'`
- **Custom Events** (dispatched on `document`):
  - `timer:state-changed` – detail: `TimerState`
  - `timer:tick` – detail: `TimerState`
  - `timer:finished` – detail: `{ mode: TimerMode }`
  - `timer:mode-changed` – detail: `{ mode: TimerMode }`

## API Contract (Interfaces)

All JavaScript modules use ES6 `export` and are loaded with `<script type="module">`.

### `pomodoro/timer.js`

- `constructor(config: { workDuration?: number, breakDuration?: number, onStateChange?: (state: TimerState) => void, ... })`
- `start()`
- `pause()`
- `reset()`
- `skip()`

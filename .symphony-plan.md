## API Contract
- Event names (all modules use these exact strings):
  - `'match'` – emitted when two tiles are successfully removed. Data: `{ tile1: Tile, tile2: Tile }`
  - `'invalid'` – emitted on an invalid attempt. Data: `{}`
  - `'start'` – emitted once on the first match of the game. Data: `{}`
  - `'gameOver'` – emitted when the board is cleared. Data: `{}`
- Module initialization signatures:
  - `ui.initGame(svgElement, scoreElement, bus)` – must attach click handlers, use `bus` to emit events.
  - `sound.initSound(bus)` – subscribes to events and plays `<audio>` by id.
  - `particles.initParticles(bus, container)` – subscribes to `'match'` and creates particle effects inside `container`.
  - `background.applyBackground(container)` – sets the background image of `container`.
- Rendering calls (available from `renderer.js`):
  - `renderer.createBoardSvg(board, svgElement)` – redraws the board
  - `renderer.animatePath(svg, path, onComplete)` – animates a connection line
- Board manipulation (available from `game.js`):
  - `board.remove(row, col)` – removes a tile from the grid
  - `PathFinder.findPath(board, start, end)` – returns path or `null`

## Shared Types

- **TimerState** (object): `{ mode: 'work' | 'break', timeRemaining: number (seconds), isRunning: boolean, workDuration: number, breakDuration: number, sessionCount: number }`
- **TimerMode** (type): `'work' | 'break'`
- **Custom Events** (dispatched on `document`):
  - `timer:state-changed` – detail: `TimerState`
  - `timer:tick` – detail: `TimerState`
  - `timer:finished` – detail: `{ mode: TimerMode }`
  - `timer:mode-changed` – detail: `{ mode: TimerMode }`

## API Contract (Interfaces)

All JavaScript modules use ES6 `export` and are loaded with `<script type="module">`.

### `pomodoro/timer.js`
Default export class `PomodoroTimer`:
- `constructor(config: { workDuration?: number, breakDuration?: number, onStateChange?: (state: TimerState) => void, ... })`
- `start()`
- `pause()`
- `reset()`
- `skip()`
- `getState(): TimerState`
- `setDuration(mode: TimerMode, seconds: number)`
The timer internally calls `tick()` every second, dispatches `timer:state-changed`, `timer:tick`, `timer:finished`, and `timer:mode-changed` events on `document`.

### `pomodoro/visuals.js`
Exports:
- `initVisuals(): (state: TimerState) => void`
- `updateVisuals(state: TimerState)` (the returned function)
- (optional) `playAnimation(type: string)` for special animations

### `pomodoro/sound.js`
Exports:
- `initSounds()`
- `playTick()`
- `playAlarm()`
- `playStart()`
All sounds are synthesized via Web Audio API; no external files required.

### `pomodoro/settings.js`
Exports:
- `Settings` class:
  - `constructor(defaults?: object)`
  - `load(): object`
  - `save(state: object): void`
  - `get(key: string): any`
  - `set(key: string, value: any): void`
  - `onChange(callback: (changed: object) => void)`
  - default values: `{ workDuration: 1500, breakDuration: 300, soundEnabled: true, backgroundTheme: 'default' }`
- `initSettings(): void` (binds UI elements in settings panel to Settings instance, updates timer on change)

### `pomodoro/background.js`
Exports:
- `initBackground(): void` (fetches background image from `https://api.nanobanana2.com/generate?prompt=pomodoro&theme=...` or similar, applies as full-screen background)
- `updateBackground(theme: string): void` (re-fetches with new theme)

## Naming Conventions

- **CSS classes**: prefix `pm-` (e.g., `pm-timer`, `pm-controls`, `pm-settings`, `pm-svg-ring`). Use kebab-case.
- **JS variables/functions**: camelCase.
- **File names**: lowercase with hyphens (already defined).
- **HTML id attributes**: also prefix with `pm-` (e.g., `pm-timer-display`, `pm-start-btn`).
- **Event names**: use `timer:` namespace for timer events.

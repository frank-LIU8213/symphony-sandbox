## Shared Types
- `AnimationState`: `{ id: string, duration: number, keyframes: string[] }`
- `AudioAsset`: `{ id: string, src: string, type: 'sfx' | 'ambient' }`
- `SectionData`: `{ id: string, title: string, content: string, svgId: string, audioCue: string, highlightLayer?: string }`
- `PlutoModelConfig`: `{ radius: number, rotationSpeed: number, layers: string[], metadata: Record<string, string> }`
- `PlutoModelAPI`: `render(container: HTMLElement, config: PlutoModelConfig): void`, `setHighlight(layer: string): void`, `resetHighlight(): void`
- `SectionAPI`: `renderSections(sections: SectionData[], container: HTMLElement): void`, `setupScrollObserver(): void`
- `AudioAPI`: `initAudio(): void`, `play(id: string, volume?: number): void`, `pauseAll(id?: string): void`, `setMasterVolume(v: number): void`, `registerAudioAssets(assets: AudioAsset[]): void`

## API Contract
- `animations.js`: `registerAnimation(config: AnimationState): void`, `trigger(id: string): void`, `cleanup(): void`
- `pluto-model.js`: `render(container: HTMLElement, config: PlutoModelConfig): void`, `setHighlight(layer: string): void`, `resetHighlight(): void`
- `sections.js`: `renderSections(sections: SectionData[], container: HTMLElement): void`, `setupScrollObserver(): void`
- `audio.js`: `initAudio(): void`, `play(id: string, volume?: number): void`, `pauseAll(id?: string): void`, `setMasterVolume(v: number): void`, `registerAudioAssets(assets: AudioAsset[]): void`
- `content.js`: `loadSections(): Promise<SectionData[]>`, `loadPlutoData(): PlutoModelConfig`
- `app.js`: `init(): Promise<void>`

## Naming Conventions
- Files: kebab-case for CSS/SVG, camelCase for JS.
- Exports: named exports for all public APIs.
- Types: PascalCase for interfaces/types.
- Data IDs: kebab-case (e.g., `sfx-hover`, `pluto-core`).
- CSS classes: BEM-like or utility-first, prefixed with `pluto-` (e.g., `pluto-section`, `pluto-model-layer`).

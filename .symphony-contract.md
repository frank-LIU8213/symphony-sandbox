## Shared Types

- `AudioConfig`: `{ url: string, volume: number, loop: boolean }` - Configuration for an audio asset.
- `AnimationState`: `{ time: number, delta: number }` - State passed to animation frames.
- `SceneInterface`: Abstract interface for all feature modules.
  - `init(container: HTMLElement): void`
  - `update(state: AnimationState): void`
  - `destroy(): void`

## API Contract

- `AudioController` (in `engine.js`):
  - `play(name: string, volume?: number): void`
  - `stop(name: string): void`
  - `setGlobalVolume(vol: number): void`
- `AnimationLoop` (in `engine.js`):
  - `start(callback: (state: AnimationState) => void): void`
  - `stop(): void`
- `Scene` implementations (in feature files):
  - Must implement `SceneInterface`.
  - `PlutoScene`, `OrbitScene`, `TimelineScene`.

## Naming Conventions

- **Classes**: `PascalCase` (e.g., `AudioController`, `PlutoScene`).
- **Functions/Variables**: `camelCase` (e.g., `playSound`, `animationState`).
- **CSS Classes**: `kebab-case` (e.g., `.tech-card`, `.orbit-path`).
- **Constants**: `UPPER_SNAKE_CASE` (e.g., `DEFAULT_VOLUME`).
- **Files**: `kebab-case` (e.g., `pluto.js`, `styles.css`).

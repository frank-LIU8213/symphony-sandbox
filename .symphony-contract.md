# Shared Types

```ts
type Medication = {
  id: string;
  name: string;
  dosage: string;
  schedule: Schedule;
};

type Schedule = {
  type: 'daily' | 'weekly' | 'biweekly' | 'monthly' | 'biannual' | 'customDays' | 'customInterval';
  times: string[];  // "HH:MM"
  // Optional fields depending on type:
  days?: number[]; // 0-6, customDays/weekly
  startDate?: string; // ISO date, for biweekly/monthly/biannual/customInterval
  intervalValue?: number; // for biweekly (default 2), biannual (default 6), customInterval
  intervalUnit?: 'day' | 'week' | 'month'; // for customInterval
  dayOfMonth?: number; // for monthly
};

type Dose = {
  id: string;
  medicationId: string;
  scheduledTime: Date;
  taken: boolean;
  takenAt?: string;
};

type HistoryEntry = {
  doseId: string;
  medicationName: string;
  takenAt: string; // ISO
};
```

# API Contract

## schedule.js
- `window.MedRemSchedule.getUpcomingDoses(medications: Medication[]): Dose[]`
- `window.MedRemSchedule.SCHEDULE_TYPES` (object with string constants: DAILY, WEEKLY, BIWEEKLY, MONTHLY, BIANNUAL, CUSTOM_DAYS, CUSTOM_INTERVAL)

## notifications.js
- `window.MedRemNotifications.initNotifications(settings?: { enableSound?: boolean, enableNotification?: boolean }): void`
- `window.MedRemNotifications.checkAndNotify(doses: Dose[]): void`
- `window.MedRemNotifications.setSoundEnabled(enabled: boolean): void`
- `window.MedRemNotifications.setNotificationEnabled(enabled: boolean): void`
- `window.MedRemNotifications.acknowledgeDose(doseId: string): void`

## logging.js
- `window.MedRemLogging.initLogging(storageKey: string): void`
- `window.MedRemLogging.markDoseTaken(doseId: string, medicationName?: string): void`
- `window.MedRemLogging.getHistory(filter?: { medicationName?: string, fromDate?: Date, toDate?: Date }): HistoryEntry[]`
- `window.MedRemLogging.clearHistory(): void`
- `window.MedRemLogging.exportHistory(): string` // returns JSON

## background.js
- `window.MedRemBackground.initBackground(containerId: string, options?: { apiKey?: string, theme?: string }): Promise<void>`

# Naming Conventions
- File names: lowercase, no hyphens (use underscores if needed, but current: `medications.js`, `logging.js`, `schedule.js`, `notifications.js`, `main.js`, `styles.css`, `background.js`).
- Global namespace: `MedRem{Module}` (`MedRemMedications`, `MedRemSchedule`, `MedRemLogging`, `MedRemNotifications`, `MedRemBackground`).
- Functions: camelCase.
- Types (JSDoc): PascalCase.
- localStorage keys: `medrem_medications`, `medrem_history`.
- DOM id's: `medication-form`, `med-name`, `med-dosage`, `med-times`, `med-schedule-type`, `med-days`, `medication-list`, `upcoming-doses`, `history-list`, etc. Keep existing ones and add new ones for form controls (e.g., `med-biweekly-interval`, `med-monthly-day`, `med-start-date`).
- CSS classes: BEM-like (`med-item__name`, `btn--small`).

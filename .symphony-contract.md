## Shared Types

- **Direction** (enum): `UP`, `DOWN`, `LEFT`, `RIGHT`.
- **BeanType** (dataclass):
  - `name: str`
  - `symbol: str` – single character to render
  - `color: int` – curses color pair ID
  - `effect: Optional[str]` – effect identifier if any, else `None`
  - `probability: float` – relative spawn weight (≥0)
- **Bean** (dataclass): `x: int`, `y: int`, `type: BeanType`.
- **Drawable** (Protocol):
  - method `draw(window: curses.window, board_x: int, board_y: int) -> None` – called by the renderer to draw extra items (e.g. effect indicators). `board_x/board_y` are the top‑left corner of the playable area on the curses window.
- **EffectHandler** (Protocol):
  - `apply(state: GameState, effect_type: str) -> None` – mutate `state` as needed (change speed, invert controls, apply shield flag, etc.).
  - `get_drawable(state: GameState, effect_type: str) -> Optional[Drawable]` – return a drawable that will be added to `state.drawables` while the effect is active, or `None`.
- **GameState** (class, defined in `snake/game.py`):
  - Attributes:
    - `snake: List[Tuple[int, int]]` – list of (x,y) from head to tail.
    - `direction: Direction`
    - `beans: List[Bean]`
    - `score: int`
    - `game_over: bool`
    - `tick_interval: int` – game speed in milliseconds (lower = faster)
    - `drawables: List[Drawable]` – extra drawables that the renderer draws on top
    - `effects_handlers: List[EffectHandler]` – registered handlers from `snake.effects`
    - `active_effects: List[Tuple[str, int]]` – `(effect_type, remaining_ticks)`; effects are processed each tick
    - board width/height attributes provided by the integrator (e.g. `board_w: int`, `board_h: int`)
  - Methods:
    - `add_drawable(d: Drawable) -> None`
    - `remove_drawable(d: Drawable) -> None`
    - `add_effect(effect_type: str, duration_ticks: int) -> None` – add or refresh an effect.
    - `tick_effects() -> None` – decrement durations, remove expired ones and remove their drawable (using `remove_drawable`).
    - `apply_effect(effect_type: str) -> None` – call the first `EffectHandler` whose `apply` matches the type.

## API Contract

### Module: `snake.beans`
- **`init_beans() -> List[BeanType]`**  
  Returns all bean types available for spawning (including the normal bean and any special ones). The integrator merges this list and uses the `probability` field to weight random bean placement.

### Module: `snake.effects`
- **`init_effects() -> List[EffectHandler]`**  
  Returns all effect handler instances. The integrator calls this once at startup and stores the result in `state.effects_handlers`.

### Module: `snake.menu`
- **`title_screen(stdscr: curses.window) -> Optional[str]`**  
  Shows the start screen. Returns `"start"` to begin the game, `"highscores"` to view high scores, or `None` to exit.
- **`game_over_screen(stdscr: curses.window, score: int) -> bool`**  
  Shows the game over screen with the final score. Returns `True` if the player chooses to replay, `False` to quit.

### Module: `snake.highscore`
- **`save_high_score(name: str, score: int) -> None`**  
  Persists a new score entry (implementations may prompt for name inside the function or take it as argument – the integrator will provide it).
- **`get_high_scores() -> List[Tuple[str, int]]`**  
  Returns the sorted high‑score list (highest first).

### Integration Flow (owned by integrator)
1. Initialize curses and call `menu.title_screen`. If `"start"`, proceed.
2. Create a `GameState`, populate `effects_handlers = init_effects()` and spawn initial beans using `init_beans()`.
3. Enter the main loop:
   - Read input via `InputHandler.get_direction`.
   - Move the snake; check wall‑collision and self‑collision → `game_over = True`.
   - Check if the snake head coincides with a bean → apply score increase, grow snake for normal beans; for special beans call `state.apply_effect(effect_type)` and immediately `state.add_effect(effect_type, duration)`.
   - Call `state.tick_effects()` each tick.
   - Spawn new beans periodically (using weighted random from the bean types list).
   - Render via `Renderer.draw(state)`.
   - Sleep for `state.tick_interval` milliseconds.
4. When `state.game_over`, call `menu.game_over_screen`; if replay, re‑initialise the state and restart the loop.

## Naming Conventions
- **Modules**: lowercase with underscores (`game`, `beans`, `effects`, `input_handler`, `renderer`, `menu`, `highscore`).
- **Classes**: PascalCase (`Game`, `GameState`, `Bean`, `BeanType`, `Drawable`, `EffectHandler`, `InputHandler`, `Renderer`).
- **Functions & methods**: lowercase with underscores.
- **Private helpers**: prefix with single underscore.
- **Constants**: UPPER_CASE.

## Shared Types

- `Position`: `{ row: number, col: number }`  
- `Tile`: `{ type: number, row: number, col: number }` – `type` is an integer identifier for the symbol (1..N).  
- `Board`: represented as a 2D array `Tile[][]` (or `null` for empty cells after removal).  
- `Path`: `Array<Position>` – the ordered set of points (including start, turn corners, end) that the connecting line travels through.  

## API Contract

### game.js – Game Logic Module

- `export class Board {`  
    `constructor(width: number, height: number, tileTypes: number)`  
    `getTile(row: number, col: number): Tile | null`  
    `remove(row: number, col: number): void`  
    `isCleared(): boolean`  
  `}`
- `export class PathFinder {`  
    `static findPath(board: Board, start: Position, end: Position): Path | null`  
  `}`  
  Returns `null` if no valid path with at most two bends connecting same‑type tiles that are both present.

### renderer.js – SVG Rendering & Animation

- `export function createBoardSvg(board: Board, svgElement: SVGSVGElement): void`  
  Clears the SVG and draws a grid. Each tile is a `<rect>` with `id="tile-{row}-{col}"` and `class="tile tile-type-{type}"`. Removed cells show empty space.
- `export function animatePath(path: Path, svgElement: SVGSVGElement, callback: () => void): void`  
  Draws a polyline along the path, smoothly animates its appearance, and calls `callback` after the animation (duration ≈ 0.8 s).
- `export function removeTile(row: number, col: number, svgElement: SVGSVGElement, callback: () => void): void`  
  Fades out the tile and removes it from the DOM; calls `callback` after the fade completes.
- `export function drawScore(score: number, containerElement: HTMLElement): void`  
  Updates the score display element (id `score`) with the current score.

### ui.js – User Interaction Handler

- `export function initGame(svgElement: SVGSVGElement, scoreElement: HTMLElement): void`  
  Creates a new `Board` (10 columns × 8 rows, 4 tile types), renders it, binds click events, and manages selection state.  
  Selection flow:  
    - First click: highlight tile (CSS class `tile-selected`).  
    - Second click on a different tile: call `PathFinder.findPath`. If a path exists, animate it, then remove both tiles with animation, update score (+10), and redraw. If no path, briefly shake the selection and clear.  
    - Click on already selected tile: deselect.  
    - After each successful match, check `board.isCleared()`; when cleared, show "Congratulations!" (e.g., `alert`).
- `export function getBoard(): Board` – returns the current board instance (for testing).

### background_generator.py – Background Image Generation

- `def generate_background(output_path: str, width: int = 1024, height: int = 768) -> None`  
  Uses the “nano banana2” API (or a suitable mock) to produce a JPEG image and saves it to `output_path`.  
  When run as `__main__`, it calls `generate_background` with `static/bg.jpg` as default.

### main.js – Application Entry Point (Integrator)

- Imports `initGame` from `./ui.js`.
- On `DOMContentLoaded`, selects the SVG `#game-board` and the score `#score` and calls `initGame`.

### index.html – Page Shell (Integrator)

- Contains a `div` with `id="score"` and an `<svg>` with `id="game-board"` (width 600, height 480).
- Loads `main.js` as a module script.
- Background image is applied via CSS (`background: url('static/bg.jpg') …`).

## Naming Conventions

- All JavaScript function and method names: **camelCase** (e.g., `findPath`, `createBoardSvg`).
- File names: lowercase, single word or hyphenated (e.g., `game.js`, `background_generator.py`).
- CSS classes: `tile`, `tile-selected`, `tile-type-{n}`, `score-container`.
- SVG element `id` pattern: `tile-{row}-{col}`, `connection-path`.
- Board dimensions: **width** (columns) first, then **height** (rows) in all APIs.
- Tile types: integer from 1 to `tileTypes` (inclusive).

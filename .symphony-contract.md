## Shared Types

- **TimerState**: `"idle" | "running" | "paused"`
- **SessionMode**: `"work" | "shortBreak" | "longBreak"`
- **TimerSettings**: object `{ workDuration: number, shortBreakDuration: number, longBreakDuration: number }` (all in seconds).
- **TimerCallbacks**: `{ onTick?: (remainingSeconds: number, totalSeconds: number) => void, onComplete?: () => void }`
- **AudioAssetNames**: `'timerEnd' | 'click'`
- **AnimationController**: `{ updateProgress: (fraction: number) => void, pulse: () => void }`

## API Contract (Module Interface)

Every module exposes itself as a property of the global `window.Pomodoro` namespace. The integrator will access them through `Pomodoro.*`.

### Pomodoro.Timer
```typescript
// Factory: Pomodoro.createTimer(settings: TimerSettings) returns TimerInstance
interface TimerInstance {
  start(): void;
  pause(): void;
  reset(): void;
  getRemainingTime(): number;
  getState(): TimerState;
  setCallbacks(callbacks: TimerCallbacks): void;
}
```

### Pomodoro.Settings
```typescript
interface SettingsAPI {
  init(): void;
  getSettings(): TimerSettings;
  setMode(mode: SessionMode): void;
  getCurrentMode(): SessionMode;
  onModeChange(callback: (mode: SessionMode) => void): void;
}
```

### Pomodoro.Audio
```typescript
interface AudioAPI {
  init(): void;  // preloads sounds
  playSound(name: AudioAssetNames): void;
}
```

### Pomodoro.Animation
```typescript
Pomodoro.Animation.init(containerId: string): AnimationController
```

### Pomodoro.Background
```typescript
interface BackgroundAPI {
  setBackgroundImage(): void;  // fetches image and applies as background
}
```

## Naming Conventions

- **CSS class names**: BEM-like, `pomodoro__block--modifier`. Examples: `.pomodoro__circle`, `.pomodoro__button--start`.
- **DOM IDs**: `timer-display`, `btn-start`, `btn-pause`, `btn-reset`, `mode-selector`, `circle-progress`, `app-background`.
- **JS global namespace**: `window.Pomodoro`.
- **JS function/variable names**: camelCase.
- **Audio file paths**: `sounds/end.mp3`, `sounds/click.mp3` (files must be provided in the project).
- **Background image**: fetched from API endpoint (URL defined in Background module), resulting image used as CSS `background-image` on `#app-background`.
- **File organization**: All JS modules under `js/`, CSS under `css/`.

## Shared Types

- `SectionData`: `{ id: string, title: string, content: string, svgId: string, audioCue: string }` — Represents a scrollable content block with associated SVG and audio.
- `PlutoModelConfig`: `{ radius: number, rotationSpeed: number, layers: string[], metadata: Record<string, string> }` — Configuration for the interactive 3D/SVG model of Pluto.
- `AudioAsset`: `{ id: string, src: string, type: 'sfx' | 'ambient' }` — Metadata for sound effects and background audio.
- `AnimationState`: `{ id: string, trigger: 'scroll' | 'click' | 'idle', duration: number, keyframes: string[] }` — Definition for SVG/CSS animations triggered by user interaction or scroll position.

## API Contract (Module Interfaces)

- `audioManager` (`js/audio.js`): `{ play(id: string, volume?: number): void, pauseAll(id?: string): void, setMasterVolume(v: number): void, initAudio(): void }`
- `contentLoader` (`js/content.js`): `{ loadSections(): Promise<SectionData[]>, loadPlutoData(): PlutoModelConfig }`
- `animationEngine` (`js/animations.js`): `{ registerAnimation(config: AnimationState): void, trigger(id: string): void, cleanup(): void }`
- `plutoModel` (`js/pluto-model.js`): `{ render(container: HTMLElement, config: PlutoModelConfig): void, handleInteraction(event: Event): void }`
- `sectionsRenderer` (`js/sections.js`): `{ renderSections(sections: SectionData[], container: HTMLElement): void, setupScrollObserver(): void }`
- `app` (`js/app.js`): `{ init(): Promise<void> }` — Orchestrates module initialization and DOM readiness.

## Naming Conventions

- Modules: camelCase (`pluto-model.js`, `audio.js`)
- Functions/Methods: camelCase (`loadPlutoData`, `handleInteraction`, `setupScrollObserver`)
- CSS Classes: kebab-case with `pluto-` prefix (`pluto-section`, `pluto-model-layer`, `pluto-nav`)
- IDs/Classes: semantic, descriptive, no generic placeholders like `div1` or `box`
- Assets: kebab-case (`pluto-atmosphere.svg`, `pluto-data.json`)
- Variables/Constants: UPPER_SNAKE_CASE for configuration constants, camelCase for runtime values.

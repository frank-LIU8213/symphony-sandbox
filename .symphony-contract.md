## Shared Types

- **AudioConfig**: `{ volume: number, enabled: boolean }` - Global audio state shared across modules.
- **AnimationState**: `{ playing: boolean, step: number }` - Per-module animation state tracking.
- **QuizResult**: `{ score: number, total: number, feedback: string }` - Quiz outcome shape.
- **SoundEffect**: Enum `[ 'fusion_start', 'fusion_complete', 'fission_start', 'fission_complete', 'correct', 'wrong' ]` - Standardized effect keys.
- **AppConfig**: `{ audio: AudioEngine }` - Configuration object passed to module `init()`.

## API Contract

- **GET /**: Serves `templates/index.html`. No parameters.
- **POST /api/quiz/submit**: Body `{ questionId: string, answer: string }`. Returns `{ success: boolean, result: QuizResult }`.
- **Module Interface**: Each JS module exports a class with `init(config: AppConfig): void` and public interaction methods (e.g., `triggerFusion()`).
- **Audio Interface**: `AudioEngine` exposes `play(effect: SoundEffect): void` and `setVolume(vol: number): void`. Modules receive an instance via constructor injection.
- **DOM Contract**: `index.html` must contain `#fusion-section`, `#fission-section`, `#quiz-section`, and `#app-header` with exact IDs matching JS selectors.

## Naming Conventions

- **Python**: `snake_case` for functions/variables, `PascalCase` for classes, `UPPER_SNAKE_CASE` for constants.
- **JavaScript**: `camelCase` for functions/variables, `PascalCase` for classes, `UPPER_SNAKE_CASE` for constants.
- **CSS**: `kebab-case` for classes/variables, `--` prefix for custom properties (e.g., `--color-primary`).
- **HTML**: `kebab-case` for attributes, `id` attributes must match JS selectors exactly.
- **SVG**: Inline SVGs use `viewBox="0 0 100 100"`. External assets use descriptive names like `fusion-core.svg`.
